# 墓地庭院地图设计

## 定位

`graveyard-courtyard` 是第一张更完整的墓地地图，用来替代过于空旷的测试场景。它仍然保持单房间结构，但通过围墙、墓碑、墓穴、树木和道路组织出更明确的移动路线。

## 结构

地图使用近似矩形庭院：

- 南侧是玩家出生点和入口缓冲区。
- 中央是主路，保证玩家有一条清晰的移动轴线。
- 左右两侧是墓碑区和障碍区，提供绕行、卡位和躲避空间。
- 北侧是出口门，击杀数达标后可以进入。
- 四周用石墙围住，破损墙段用于视觉变化，不作为通路。

## 玩法意图

玩家出生在南侧，前方有主路通向北侧出口。左右墓碑区会形成阻挡和绕行路线，丧尸追击时不会只发生在一片空地上。

中部祭坛、棺材、长椅、树和石头提供局部障碍，让玩家需要走位，但不会把路完全堵死。

## 资源规则

地图配置只写 `assetId`，不写构建后的 `modelUrl`。运行时会根据 `assetId` 按需解析 Kenney 墓地包 GLB 模型，这样重新构建后资源 hash 改变也不会导致数据库里的地图失效。

## 导入

启动后端后执行：

```bash
node scripts/import-graveyard-courtyard-map.mjs
```

默认接口地址是 `http://127.0.0.1:8088/api`。如果部署环境不同，可以指定：

```bash
API_BASE_URL=https://example.com/api node scripts/import-graveyard-courtyard-map.mjs
```
