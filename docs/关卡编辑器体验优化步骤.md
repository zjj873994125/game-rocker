# 关卡编辑器体验优化步骤

## 目标

把当前关卡编辑器从“配置导出工具”调整成更顺手的开发用地图编辑器。优化重点是工作流、视图反馈和上下文属性面板，不先做复杂商业编辑器能力。

## 步骤

- [x] 1. 重排编辑器工作流布局

  把编辑器改成固定顶部工具栏、左侧地图/资源、中央大画布、右侧上下文属性面板。

  验收标准：

  - 常用操作集中在顶部工具栏。
  - 左侧只负责后端地图和资源库。
  - 中央画布区域更大。
  - 右侧按当前上下文显示地图、对象、门、出生点属性。
  - 保存后端、刷新、载入这些动作位置更清晰。

- [x] 2. 增强选择和画布反馈

  优化选中态、当前模式状态、吸附状态和底部提示，让用户明确知道当前正在编辑什么。

  验收标准：

  - 选中对象、门、出生点时有清晰状态提示。
  - 当前模式不用读说明也能识别。
  - 吸附开关状态明显，但不干扰画布。

- [x] 3. 优化对象和门的属性编辑

  把对象、碰撞体、门、地图基础信息拆成更短的上下文面板，减少滚动和误操作。

  验收标准：

  - 未选中对象时默认显示地图信息。
  - 选中对象时优先显示对象和碰撞体。
  - 选中门时优先显示门。
  - 删除操作靠近当前选中项。

- [ ] 4. 增加快捷键

  增加选择、放置、出生点、门、删除、保存等常用快捷键。

  建议：

  - `V`：选择/编辑对象。
  - `B`：放置对象。
  - `P`：设置出生点。
  - `M`：添加门。
  - `Delete`：删除选中项。
  - `Ctrl/Cmd + S`：保存后端。
  - `Esc`：取消选中。

- [ ] 5. 增加预览和吸附反馈

  放置资源时显示半透明预览，吸附命中时显示边缘或角点提示。

  验收标准：

  - 鼠标移动时能看到即将放置的位置。
  - 吸附后能看出贴到了哪个方向。
  - 不影响现有放置、拖动和保存逻辑。

- [ ] 6. 增加后端地图管理能力

  在编辑器中支持新建地图、复制地图、删除地图、草稿/发布状态和版本查看。

  验收标准：

  - 可以从界面新建空地图。
  - 可以复制当前地图为新 ID。
  - 可以删除非当前运行地图。
  - 保存会产生版本记录。
  - 可以查看历史版本。

## 当前优先级

先做步骤 1，让编辑器整体使用路径顺起来。后续再做反馈、快捷键和版本管理。
