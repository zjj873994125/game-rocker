# 前端登录注册弹窗说明

## 功能范围

本阶段前端登录注册已经接入后端接口。页面提供全局登录弹窗，登录或注册成功后保存后端签发的 Token，后续写地图等请求会通过 `Authorization: Bearer <token>` 传给后端。

## 访问规则

- 未登录用户是游客身份，可以进入游戏页、加载地图、开始游戏。
- 游客不能进入 `/editor` 地图编辑器，访问时会回到游戏页并自动打开登录弹窗。
- 登录用户可以进入地图编辑器。
- 后续接入后端后，再由服务端判断普通用户、地图拥有者和超管权限。

## 入口交互

- 顶部账号区未登录时只显示“请登录”按钮。
- 点击“请登录”打开登录弹窗。
- 登录弹窗不显示顶部切换按钮，只保留当前标题。
- 登录提交按钮下方提供“点击注册账号”小字入口。
- 注册弹窗提交按钮下方提供“返回登录”入口。

## Token 存储

- Token 保存到 `zjj-auth-token`。
- 当前用户摘要保存到 `zjj-auth-current-user`，只用于刷新后展示昵称和角色。
- 手机号唯一、密码校验、角色和权限以后端数据库为准。

前端不能依赖本地用户信息做真正权限判断，保存地图等敏感操作必须以后端 Token 校验结果为准。

## 相关文件

- `src/stores/auth.ts`：维护当前用户、Token、登录注册弹窗状态。
- `src/game/api/authApi.ts`：登录、注册、读取当前用户接口。
- `src/game/api/authToken.ts`：Token 本地读写。
- `src/components/AuthDialog.vue`：全局登录注册弹窗。
- `src/components/AuthStatus.vue`：顶部账号状态和登录/注册/退出入口。
- `src/router/index.ts`：`/editor` 登录拦截。
- `src/App.vue`：挂载全局弹窗并在启动时恢复登录状态。
