# 便利店新关卡说明

## 目标

`mini-market-store` 是第二套非墓地风格关卡，使用 `src/game/assets/models/maps/kenney_mini-market` 资源包。它用于验证多地图房间架构可以从墓地切换到完全不同的地图素材，而不是只在墓地包内复用资源。

在关卡编辑器里，墓地固定作为第一关，便利店固定作为第二关。左侧对象库切到“第二关 / 便利店”后，只显示 `mini-market:` 前缀的便利店素材和通用占位盒；新建地图会使用 `custom-mini-market-store-xxxxxx` 作为默认 ID 前缀。

## 资源标识规则

便利店模型的 `assetId` 统一使用 `mini-market:` 前缀，例如：

- `mini-market:wall`
- `mini-market:wall-window`
- `mini-market:shelf-boxes`
- `mini-market:freezers-standing`
- `mini-market:cash-register`

这样可以避免和墓地包里的 `wall`、`floor` 等通用资源名冲突。运行时会在 `MapModelLoader` 中解析该前缀，并加载便利店资源包自己的 GLB 和贴图。

## 关卡结构

`mini-market-store` 使用便利店墙体围出一个室内房间，布局按现实便利店/小超市的常见摆放方式设计，不做随机堆物：

- 南侧中间为入口和出口门。
- 入口左侧放购物车和购物篮，符合进门先拿购物工具的动线。
- 入口右侧为收银区，收银台、员工和排队围栏靠近出口，方便离店结账。
- 中部使用三条纵向货架岛，货架之间保留可通行走廊，前后保留横向主通道。
- 北侧后墙放立式冷柜和瓶罐回收机，符合冷藏设备靠墙布置的习惯。
- 东侧靠墙放卧式冰柜、面包陈列和水果陈列，形成边墙商品区。
- 结构柱靠边摆放，不阻断主要通道。

第一版仍使用手写 box collider。可视模型只负责表现，实际阻挡由 `colliders` 控制。

## 黑暗模式

便利店作为室内第二关，运行时会启用专属黑暗模式：

- 场景背景和雾效切换为接近全黑。
- 全局半球光和方向光强度降低，但仍保留基础可见度，避免角色和货架完全消失。
- 玩家前方偏上启用一个 `THREE.SpotLight`，向人物前方照射，重点照亮前方道路。
- 玩家前方额外启用弱 `PointLight` 补光，保持当前暗场可见度。
- 地面额外叠加一个从人物前侧延伸到前方的半透明暖色光锥，用来表现手电筒在黑暗中的可见照射范围。
- 手电筒每帧跟随玩家位置，并按玩家当前朝向更新照射方向。

这个效果只在 `GameWorld` 当前地图 ID 为 `mini-market-store` 时启用，不写入地图 JSON，也不影响关卡编辑器里的地图配置。`SpotLight` 负责真实照亮地面和模型，`PointLight` 负责角色可见性，地面光锥只负责视觉提示，不参与碰撞、命中或地图逻辑。这样便利店可以有独立氛围，同时墓地关卡和后续其它地图仍然使用默认室外光照。

## 门连接

导入脚本会新增 `mini-market-store`，并把 `graveyard-courtyard` 的 `courtyard-north-exit` 指向新关卡：

```text
graveyard-courtyard -> mini-market-store
mini-market-store -> graveyard-courtyard
```

玩家达到当前地图 `requiredKills` 后，靠近门会看到提示：

```text
按 A/Space 进入：目标地图名
```

如果未达到击杀数，靠近门会提示还需要多少击杀。

编辑器中新建门也会按关卡类型填默认目标：第一关墓地的门默认连到 `mini-market-store`，第二关便利店的门默认连回 `graveyard-courtyard`。默认值只是为了减少重复输入，实际目标仍以右侧门属性面板保存的配置为准。

## 导入命令

本地后端默认地址：

```bash
AUTH_TOKEN=你的登录token node scripts/import-mini-market-map.mjs
```

指定服务器后端地址：

```bash
API_BASE_URL=https://你的域名/api AUTH_TOKEN=你的登录token node scripts/import-mini-market-map.mjs
```

如果目标地图是 `public`，普通登录用户可以更新；如果目标地图是 `private`，需要地图创建者或超管 token。

## 当前限制

- 门还没有真实开门动画，仍然通过提示和门材质表达可进入状态。
- `targetSpawnId` 仍是保留字段，切图后使用目标地图的 `spawnPoint`。
- 便利店关卡没有单独地板模型铺满全场，当前继续使用全局地板材质。
